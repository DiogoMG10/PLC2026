## Resumo
Neste trabalho foi desenvolvido um analisador léxico em Python para uma linguagem de queries, recorrendo a expressões regulares para identificar os diferentes tipos de tokens presentes no texto.

O analisador reconhece comentários, variáveis, identificadores de língua, strings, valores numéricos, delimitadores, identificadores e a palavra reservada `LIMIT`. Os comentários e os espaços em branco são ignorados durante a análise.
